## 🔦 [The Searchlight Protocol](https://github.com/DhruvGarg111/The-Searchlight-Protocol)

> *"Finding the needle in the haystack, from 400ft above."*

A **novel coarse-to-fine computer vision pipeline** designed for efficient small object detection in high-resolution (2K/4K) aerial imagery. This project tackles the critical trade-off between resolution and latency in real-world drone forensics.

**🎯 The Innovation:**
- Uses **LayerCAM (Class Activation Mapping)** to identify semantic "hotspots" first
- Intelligently slices and zooms into regions of interest — **skipping 80%+ of empty backgrounds**
- Outperforms blind sliding-window approaches (SAHI) in both speed and accuracy

**🌍 Real-World Applications:** Search & Rescue • Wildlife Conservation • Disaster Response • Border Security

## 🎨 [Neural Canvas](https://github.com/DhruvGarg111/Neural-Style-Transfer)

> *Transform any image into a masterpiece — in real-time.*

A **fast neural style transfer** implementation that generates stylized images using a feed-forward CNN trained with **perceptual loss**. Unlike optimization-based methods, this approach performs instant stylization in a single forward pass.

**✨ Key Features:**
- 🚀 **Real-time inference** — stylize images instantly
- 🧠 **Perceptual content & style loss** using pretrained VGG-16
- 🔁 **Residual architecture** with Instance Normalization for high-quality outputs
- 📦 **ONNX export** ready for edge deployment

**🏗️ Architecture:** Reflection Padding → Downsampling → 5 Residual Blocks → Upsampling → Instance Normalization
